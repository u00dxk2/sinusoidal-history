**What a fresh agent would otherwise re-derive:**

- **Tailwind v4 `max-[Npx]` means width < N, exclusive.** `max-[389px]` left a 389px
  screen out; the adversarial review caught it. Write the breakpoint you mean to exclude.
- **Shrinking uppercase nav type can drop a link under the 44px tap WIDTH even while
  `min-h-11` holds its height** — "Chart" and "About" measured ~41px at 11px/0.1em.
  `min-w-11` on the links keeps both axes on the floor.
- **To find what scrolls a page sideways, list elements whose `scrollWidth` exceeds
  their `clientWidth`**, not only boxes past the viewport edge: the `/state` culprit was
  TEXT (an unbreakable URL) overflowing a box that itself sat inside the viewport, and a
  box-edge scan found nothing.
- **`next start` launched through `npm --prefix … run start` survives a TaskStop** (the
  npm wrapper dies, the node child keeps the port). Launch `node node_modules/next/dist/bin/next
  start <dir> -p <port>` directly, or read the port's owner and stop that PID.
