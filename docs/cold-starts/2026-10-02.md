**Non-obvious:**

It restores on EVERY mount, which is I-018's bug: a fresh visit in the same tab reopens at the old place (measured on production). The fix in I-018's onTrigger is to restore only when `performance.getEntriesByType("navigation")[0].type === "back_forward"`. Back from the SVG is a full document load, so it still counts as back_forward.
- **The figure legs' size numbers are derived, not read from text boxes.** `check-verdict-landing` computes label size as the SVG's inline font size times `min(img width / 900, img height / 500)`, because an `<img>` exposes no text boxes. Its header declares a CEILING: contrived CSS (padding inside the img box, an inner overflow ancestor) can fool those legs. Two Codex rounds found that class, so it was declared, not patched a third time. Do not patch it again; a person's read is the proof.
