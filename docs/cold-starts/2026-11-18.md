### Non-obvious (round 3)

- **The flag is build-time.** `NEXT_PUBLIC_` is inlined at build, so a Render env change does nothing until `render-put-secret.mjs --deploy-latest`. With autoDeployTrigger checksPass, an env write alone never redeploys.
- **The flag-off stylesheet still declares the Plex `@font-face` rules** (`layout.tsx` imports `designPassFonts.ts` at module scope and gates only the class names). They are not preloaded or fetched. This is true again in a rollback.
- **`holdsUp.test.ts:54` expects "Not tested —" and fails with the flag ON** (the variant's empty state reads "Not tested."). CI builds and tests with the flag off, so CI never sees it. Fix it with I-078's words on 11-19, not before.
- **Do not build in a worktree whose `node_modules` is a junction.** Turbopack refused to resolve `next` through it ("Could not find the Next.js package") and the admit was wasted after 20 minutes in the queue. Build from the main checkout.
- **The `[data-dp] header > p` rule restyles the lede on any page that gets `data-dp`.** That is what pushed /methods over. Re-budget a page's first screen before adding `data-dp`.
- **No error instrument covers visitors.** There is no Sentry and no client analytics. `scripts/crawl-read.mjs` judges status for crawler rows only.
