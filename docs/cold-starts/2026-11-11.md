### Non-obvious (11-11)

- **Tailwind 4 `max-[Npx]:` compiles to `(width < Npx)`, strict** (Codex r2 read the installed source). The readout's width switch is 345px in `TimeRangeBrush.tsx`, and the checker uses `vw < 345`. `brushStatus.test.ts` fails if the two numbers part.
- **The long note leaves the "Range" line at 338px and fits at 339px** (production, text set in place). 345 is slack on purpose. A longer readout needs re-measuring at 320, 338 and 345.
- **"nothing drawn after <year>" is true only because of the data files.** Neither `parseCsvSeries` nor the event layer caps at the current year. Two legs in `brushStatus.test.ts` fail if a loaded series row or an event marker is dated later. Adding data from the current year is fine; adding a later one turns CI red, which is the intended behaviour.
- **Any script that reads the readout uses `[data-range-readout]`.** It no longer starts with "showing".
