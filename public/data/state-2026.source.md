## The freeze contract

This file is the 2026 edition **as published** and is never recomputed. The
live `/state/2026` page recomputes from the current cycle definitions, so if
a period or anchor is ever corrected the page will update (with the
correction recorded in the project changelog) while this CSV stays fixed.
Cite the CSV when you need the number as it stood at publication; cite the
page when you want the current best derivation.

Published with ten cycles (Phase 14 roster). One edition file per year is
committed at publication; the `/state/<year>` page links it when it exists.
