# State of the Cycles — frozen 2026 edition

> **Retired 2026-10-21.** The yearly `/state/<year>` pages and `/api/v1/state` are retired:
> the site now draws each cycle as one period around its reference peak, up to the present,
> and no longer states where any year sits on a cycle. `/state/*` redirects to `/cycles`, and
> `/api/v1/state` answers 410 Gone. This file stays as published, under the freeze contract
> below, so a citation of it still resolves. Its rows are the site's cosine values at 2026,
> including values outside some cycles' drawn periods; they are not forecasts, and the site no
> longer endorses reading them as where the cycles stand.
>
> Everything below this note is the original publication documentation, kept as published.

**Published:** 2026-08-18
**Derivation:** Generated from `/api/v1/state?year=2026` at publication time —
the same `stateOfCycles()` derivation the live `/state/2026` page renders
(cos(2π · (year − reference_peak_year) / period_years), phase labels per the
±3%/±1.5% editorial bands, next extrema rounded to whole years).

## The freeze contract

This file is the 2026 edition **as published** and is never recomputed. The
live `/state/2026` page recomputes from the current cycle definitions, so if
a period or anchor is ever corrected the page will update (with the
correction recorded in the project changelog) while this CSV stays fixed.
Cite the CSV when you need the number as it stood at publication; cite the
page when you want the current best derivation.

Published with ten cycles (Phase 14 roster). One edition file per year is
committed at publication; the `/state/<year>` page links it when it exists.
